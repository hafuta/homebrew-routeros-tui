# Homebrew tap for MikroTik TUI

Prebuilt macOS binaries for [hafuta/mikrotik-tui](https://github.com/hafuta/mikrotik-tui). A normal install does not need a Rust compiler or an Apple Developer account.

```sh
brew tap hafuta/mikrotik-tui
brew install mikrotik-tui
```

Upgrade with `brew update && brew upgrade mikrotik-tui`.

`brew install --HEAD mikrotik-tui` builds from `master` and requires Homebrew `rust`.
